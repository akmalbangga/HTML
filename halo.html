Tentang Web Development

Web development adalah proses membuat dan mengembangkan sebuah website. Dalam prosesnya diperlukan beberapa tools seperti text editor, browser, server lokal, HTML, CSS, dan JavaScript.

Berikut merupakan tahapan sederhana yang dapat dilakukan untuk mempersiapkan lingkungan development web.

Tahapan Instalasi

1

Persiapkan Komputer

Pastikan komputer atau laptop sudah siap digunakan dan memiliki koneksi internet untuk mengunduh software yang diperlukan.

2

Install VS Code

Download dan install Visual Studio Code sebagai text editor untuk menulis kode HTML, CSS, JavaScript, dan bahasa pemrograman lainnya.

3

Install Browser

Install browser seperti Google Chrome atau Mozilla Firefox untuk menjalankan dan menguji website yang dibuat.

4

Install XAMPP

XAMPP digunakan sebagai server lokal apabila website membutuhkan PHP dan database MySQL.

5

Buat Folder Project

Buat folder khusus untuk menyimpan file project website seperti index.html, style.css, dan script.js.

6

Buat File HTML

Buat file bernama index.html kemudian tuliskan struktur dasar HTML sebagai halaman utama website.

7

Tambahkan CSS

CSS digunakan untuk mengatur tampilan website, seperti warna, ukuran tulisan, posisi, layout, dan desain.

8

Jalankan Website

Buka file index.html menggunakan browser untuk melihat hasil website yang telah dibuat.

Tools Development Web

HTML

Digunakan untuk membuat struktur atau kerangka halaman website.

CSS

Digunakan untuk mengatur tampilan dan desain website agar lebih menarik.

JavaScript

Digunakan untuk membuat website menjadi interaktif dan memiliki fungsi tertentu.

Visual Studio Code

Text editor yang digunakan untuk menulis dan mengelola kode program website.

Google Chrome

Browser yang digunakan untuk menjalankan dan melakukan testing terhadap website.

XAMPP

Digunakan sebagai server lokal untuk menjalankan PHP dan database MySQL.

Tips Development Web

  • Gunakan struktur folder yang rapi.
  • Gunakan nama file yang mudah dipahami.
  • Biasakan melakukan testing di browser.
  • Simpan project secara berkala.
  • Pelajari HTML terlebih dahulu sebelum masuk ke CSS dan JavaScript.
  • Gunakan Git/GitHub untuk menyimpan versi project.
